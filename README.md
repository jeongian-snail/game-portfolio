# 정이안의 게임팩 선반

선반에서 게임팩을 고르면 본체에 팩이 꽂히고 모니터가 켜진다. 모니터에 비친 게임 화면을 따라 확대하면 작품 소개가 열린다. [포트폴리오 열기](https://jeongian-snail.github.io/game-portfolio/)

| 게임팩 | 화면 |
| --- | --- |
| 신록의 섬 · 개발 중 | 리프의 정원에서 촬영한 실제 플레이 영상 |
| 요주 | 2인 비공개 봇전에서 주사위 굴림·보관·다시 굴리기를 촬영한 실제 플레이 영상 |
| 냥냥드롭 | 고양이가 떨어지고 합쳐지는 실제 플레이 영상 |

세 플레이 영상은 각각 60초다. 신록의 섬은 리프의 대사가 모두 표시된 다섯 장면에서 각각 1초씩 더 머문다.

작품 사이를 옮기려면 다른 팩을 선택한다. ‘팩 꺼내기’ 버튼이나 Esc 키로 선반에 돌아올 수 있다. 운영체제에서 동작 줄이기를 설정하면 작품 상세 화면이 바로 열린다.

GitHub Pages는 `main` 브랜치의 루트를 게시한다. 로컬에서는 저장소 루트에서 `python3 -m http.server 8080`을 실행한다. [이전 작업 지도 버전](https://github.com/jeongian-snail/game-portfolio/tree/bd2d25afaf033f392fe180cc2a02fb411a7bdf20)
