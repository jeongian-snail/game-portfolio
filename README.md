# 정이안 게임 개발 포트폴리오

[이안의 작업 지도 열기](https://jeongian-snail.github.io/game-portfolio/)

신록의 섬 작업 지도에서 개발 중인 **신록의 섬**, **요주**, **냥냥드롭**을 차례로 소개한다. 지도와 목록에서 같은 게임 기록으로 이동할 수 있다.

## 실행

`index.html`을 열거나 저장소 루트에서 `python3 -m http.server 8080`을 실행한다. GitHub Pages에서는 main 브랜치의 루트를 사용한다.

## 게임과 미디어

- **신록의 섬**은 Unity로 개발 중인 2.5D 재배·정화 게임이다. 리프의 정원과 소리의 자동 수확을 담은 2026-11-20 실제 플레이 녹화, 첫 가구 배치와 복귀 수확 보고 화면을 사용한다. 게스트 체험은 [게임 홈페이지](https://isle-of-verdure.com/)로 연결한다.
- **요주**는 공개 4인 봇전의 눈금 조절기 컷신 원본을 사용한다. [게임](https://yoju.duckdns.org/)
- **냥냥드롭**은 실제 플레이 녹화와 이전 포트폴리오의 스크린샷을 사용한다. 시드 실험은 게임의 등장 난수 계산을 사용한다. [소스](https://github.com/jeongian-snail/nyang_drop)
- 지도와 리프는 신록의 섬 게임 아트다. 요주와 냥냥드롭의 지도 캐릭터는 포트폴리오용 재해석이다. [고운바탕 라이선스](assets/atlas/OFL.txt)

작품별 기록을 Unity와 웹게임으로 필터링할 수 있다. 이미지 확대, PDF 인쇄, 모바일 메뉴와 연락 링크를 지원한다. 개발 과정의 AI 협업 범위를 각 작품에 기재한다.
